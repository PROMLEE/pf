# 개인 자산 화면

## 인증과 데이터베이스

`meet_in_the_middle`은 Supabase Auth가 아닌 NextAuth의 카카오·네이버 로그인과 Supabase PostgreSQL의 `public."User"` 테이블을 사용합니다. 이 앱도 동일한 제공자 키, `AUTH_SECRET`, `DATABASE_URL`을 서버 환경 변수로 읽어 기존 사용자 ID를 공유합니다. `apps/web/.env.example`을 참고해 `.env.local`을 설정하고 http://localhost:3000 에서 실행하세요. 두 앱의 세션 쿠키를 같은 브라우저에서 공유하려면 호스트 이름도 동일하게 `localhost`로 사용해야 합니다.

자산 테이블 정의는 [sql/portfolio_schema.sql](../../sql/portfolio_schema.sql)에 있습니다. 공유 Supabase 프로젝트에 적용된 `portfolio` 스키마는 Data API에 노출하지 않았고 `anon`·`authenticated` 권한을 부여하지 않았습니다. 모든 자산 요청은 Next.js 서버에서 로그인 사용자 ID로 범위를 제한합니다. DB 비밀번호와 OAuth 비밀 키는 브라우저로 보내지 않습니다.

가상자산 보유량과 시세 저장 테이블은 [sql/portfolio_crypto_assets.sql](../../sql/portfolio_crypto_assets.sql)에 있습니다. 기존 공유 Supabase 프로젝트에 적용되어 있습니다.

기존 가상자산에 원화 매입단가를 추가하는 변경은 [sql/portfolio_crypto_average_cost.sql](../../sql/portfolio_crypto_average_cost.sql)에 있습니다. 매입단가를 모르는 기존 자산은 빈 값으로 유지합니다.

KIS 접근 토큰은 [sql/portfolio_kis_token_cache.sql](../../sql/portfolio_kis_token_cache.sql)의 비공개 서버 테이블에 암호화해 보관합니다. 서버가 재시작되거나 Vercel 인스턴스가 바뀌어도 만료 전 토큰을 재사용하며, 만료 후 첫 시세 조회에서만 다시 발급합니다. 이 테이블은 브라우저나 Supabase Data API에 공개하지 않습니다.

기존 DB에 추가할 환율 수정 시각·입출금 기록 테이블 변경은 [sql/portfolio_cash_flows.sql](../../sql/portfolio_cash_flows.sql)에 있습니다. 공유 Supabase 프로젝트에 이미 적용되어 있습니다.

## 캡처 가져오기

메리츠 국내·해외 및 미래에셋 전체 계좌 잔고 화면을 Tesseract.js가 브라우저에서 분석합니다. 미래에셋은 국내주식만 읽고 평가금액·매입금액을 보유 수량으로 나눠 주당 가격과 매입단가를 계산합니다. CMA/RP와 퇴직신탁은 주식 가져오기에서 제외됩니다. 인식한 종목명·코드·수량·가격·매입단가를 확인한 뒤 저장하세요. 잘려 보이는 ETF 이름과 코드에는 수동 수정이 필요할 수 있습니다. 매입단가가 없는 종목은 평가손익 계산에서 제외됩니다.

이미지는 서버에 보내거나 저장하지 않습니다. 확인한 종목 데이터만 계정의 자산 테이블에 보관합니다. 같은 증권사·계좌·시장·종목 코드를 다시 가져오면 기존 종목을 교체합니다. 코드가 없는 항목은 잘린 이름이 같아도 합치지 않습니다.

저장한 주식의 수량과 매입단가, 비트코인 등 가상자산의 보유 수량과 코인당 매입가, 현금·기타 자산 금액은 **자산 수정** 화면에서 관리합니다. 이 화면의 **종목코드 확인·변경**은 시세 조회에 사용할 코드와 거래소를 한국투자증권 종목 마스터에서 확인합니다. 가상자산과 현금 변경은 **변경 내용 저장**을 눌러 반영합니다. 목표 비중, 리밸런싱, 자산 기록도 각각 전용 화면에서 확인합니다.

이전 버전에서 브라우저 localStorage에 저장한 자산이 있으면 로그인 후 이전 버튼이 표시됩니다. 사용자가 버튼을 눌러야 계정 데이터로 옮겨집니다.

## 가격 조회

[한국투자증권 Open API](https://github.com/koreainvestment/open-trading-api)의 국내·해외 현재가 조회를 사용합니다. `KIS_APP_KEY`, `KIS_APP_SECRET`을 `.env.local`에 설정하고 개발 서버를 재시작하세요. 키는 서버에서만 사용됩니다. OCR 검토 화면의 `KIS 코드 찾기`는 한국투자증권이 배포하는 KOSPI·KOSDAQ·NASDAQ·NYSE·AMEX 종목 마스터 파일로 종목명·티커·거래소를 확인하며 API 키 없이 사용할 수 있습니다. 이름이 잘린 종목은 후보를 직접 선택합니다. 키가 없으면 저장된 캡처 가격을 표시합니다. 저장된 평가액을 먼저 보여주고, 화면이 열려 있을 때 주식 시세는 약 5분마다, 빗썸 원화 시세는 약 1분마다 갱신을 시도합니다. 수동 가격 갱신도 가능합니다. REST 조회이므로 체결 실시간 구독은 아닙니다.

보유 자산 화면은 원화와 달러 평가액을 별도로 표시합니다. 대시보드는 자동 갱신한 USD/KRW 기준환율로 합산하며, 외부 환율 조회를 기다리지 않고 마지막 저장 환율로 먼저 표시합니다. 국내 종목 코드를 모르면 가격 조회에서 제외됩니다.

가상자산은 [빗썸 원화마켓 목록](https://apidocs.bithumb.com/docs/%EB%B9%A0%EB%A5%B8-%EC%8B%9C%EC%9E%91-%EA%B0%80%EC%9D%B4%EB%93%9C)에서 종목명이나 `KRW-BTC` 코드를 검색해 등록합니다. 보유 수량과 코인당 매입단가는 사용자가 입력하며, [빗썸 공개 현재가](https://apidocs.bithumb.com/reference/%ED%98%84%EC%9E%AC%EA%B0%80-%EC%A1%B0%ED%9A%8C)를 서버에서 조회해 원화 평가액과 평가손익을 계산합니다. 포트폴리오 저장·가격 갱신 시 조회하고, 화면이 열려 있으면 약 1분마다 재조회합니다. API 키 없이 가격을 조회하지만 거래소 계좌의 수량을 자동으로 읽지는 않습니다. 조회에 실패하면 마지막 저장 가격과 조회 시각을 표시합니다. 계좌 수량 자동 동기화에는 별도 빗썸 Private API 인증이 필요합니다.

## 포트폴리오 설계와 기록

첫 화면에서 예시 구성 또는 빈 포트로 시작합니다. 포트 이름·목표 비중·색상을 편집하고 **목표 설계 → 리밸런싱 허용 오차**에서 목표와 현재 비중의 허용 차이(%p)를 정할 수 있으며 목표 합계가 100%일 때 저장됩니다. 보유 종목의 포트 지정은 **자산 배정** 화면에서 관리합니다. 리밸런싱에서 아직 보유하지 않은 매수 후보를 KIS 종목 마스터로 검색해 등록할 수 있으며, 종목코드 규칙보다 직접 배정이 우선합니다. 가상자산은 원화마켓 코드와 수량으로 등록하며, 현금·RP 같은 항목은 원화 금액 또는 달러 수량으로 직접 입력합니다.

원형 그래프와 범례는 현재/목표 보기에서 해당 비중이 큰 순서대로 표시합니다. 현재 비중은 국내 자산 원화 평가액, 미국 자산과 달러 직접 입력 자산에 USD/KRW 환율을 곱한 값, 원화 직접 입력 자산을 합쳐 계산합니다. 자동 환율은 [Frankfurter의 ECB 일일 기준환율](https://frankfurter.dev/)을 사용하며 API 키가 필요 없습니다. 포트폴리오를 열면 기준일과 환율을 확인해 저장하고, 실패하면 마지막 저장값을 유지합니다. 장중 실시간 환전 가격과는 다릅니다. **목표 비중 편집 → 환율·기타 설정**에서 직접 입력 모드로 바꿀 수도 있습니다. 미분류 자산이나 가격 없는 종목이 있으면 리밸런싱 추천을 보류합니다. 매도 후 매수는 예상 매도 대금 안에서, 신규 자금 매수는 입력한 금액 안에서 정수 주 단위로 제안합니다. 종목을 이번 조정에서 제외할 수 있고, 조정 후 예상 비중과 남는 금액을 보여줍니다. 계좌별 주문 가능 금액·수수료·세금·환전 비용은 반영하지 않으며 실제 주문은 실행하지 않습니다.

포트폴리오 저장, 자산 가져오기·삭제·종목코드 수정, 가격 갱신, `오늘 기록` 버튼으로 한국 날짜 기준 일별 평가액이 기록됩니다. 같은 날짜에는 최신 평가액으로 갱신되며 과거 날짜 기록은 유지됩니다.

입출금 기록은 계좌 밖에서 유입되거나 인출된 원화 금액을 사용자가 입력합니다. 전체 자산의 두 기록 날짜 사이 평가액 변화에서 그 기간의 순입금을 뺀 참고 증감을 표시합니다. 새로운 보유 자산 등록, 수량 수정, 배당·수수료·환율 변동을 분리하지 않으므로 투자 수익률로 해석하면 안 됩니다.
