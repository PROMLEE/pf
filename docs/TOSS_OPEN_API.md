# 토스증권 시세 공급자 연동

2026-10-22 기준. 공식 OpenAPI 1.2.24 명세로 구현했습니다.

## 지원 범위

- KIS와 토스증권 중 서버에서 우선 시세 공급자를 지정합니다.
- 실패한 종목만 보조 공급자에서 다시 조회합니다. 두 가격을 섞거나 평균내지 않습니다.
- 토스: 국내·미국 현재가 최대 200종목 일괄 조회, 종목명·코드 검색, 전일 종가 조회.
- 코스피·코스닥, NASDAQ·NYSE·AMEX를 기존 앱의 시장·거래소 코드로 변환합니다.
- 계좌 조회·자동 주문·가상자산·토스 환율 및 장 운영 시간 연동은 이번 범위에 포함하지 않았습니다.

## 서버 설정

`apps/web/.env.example`의 다음 항목을 로컬 `.env.local`과 실제 배포 프로젝트 환경변수에 설정합니다. 키를 Git에 커밋하거나 `NEXT_PUBLIC_` 변수로 만들지 않습니다.

```dotenv
STOCK_DATA_PROVIDER=kis
STOCK_DATA_FALLBACK=true
TOSS_CLIENT_ID=
TOSS_CLIENT_SECRET=
```

| 설정 | 동작 |
| --- | --- |
| `STOCK_DATA_PROVIDER=kis` | KIS 우선. 기존 기본 동작입니다. |
| `STOCK_DATA_PROVIDER=toss` | 토스 우선. 다건 현재가 조회를 사용합니다. |
| `STOCK_DATA_FALLBACK=true` | 설정된 보조 공급자에서 실패 종목만 재조회합니다. |
| `STOCK_DATA_FALLBACK=false` | 지정한 공급자만 사용합니다. |

우선 공급자의 키가 없고 보조 조회가 켜져 있으면 설정된 다른 공급자를 사용합니다. 둘 다 키가 없으면 주식 시세는 갱신하지 않습니다. KIS 공개 종목 마스터 검색과 빗썸 시세 경로는 계속 사용할 수 있습니다.

사용자 설정의 **주식 시세 공급자**에서 적용된 우선 공급자와 보조 조회 여부를 확인할 수 있습니다. 이 표시는 서버 설정이며 실제 연결 성공을 검사하는 진단 기능은 아닙니다. 변경하려면 서버 환경변수를 수정하고 재배포합니다.

## 토스 계정과 허용 IP

1. 토스증권 WTS의 설정 → Open API에서 클라이언트 키를 발급합니다.
2. 실제 서버의 외부 호출 IP를 토스 허용 IP에 등록합니다.
3. 키를 서버 환경변수로 등록하고 재배포합니다.
4. 포트리듬에서 가격 갱신을 실행해 현재가·전일 종가와 실제 공급자 표시를 확인합니다.

토큰 발급 요청에도 허용 IP 조건이 적용됩니다. IP 미등록 403에서는 토큰을 반복 발급하지 않으며, 보조 조회가 켜져 있으면 KIS를 사용합니다.

Vercel 기본 외부 호출 IP는 고정되어 있지 않습니다. 배포 계정에서 **Static IPs** 등 고정 출구 IP를 먼저 구성하고 해당 주소를 등록해야 합니다. 이 저장소 작업에서는 다른 계정의 Vercel 설정을 변경하지 않았습니다.

- [토스 공식 인증 문서](https://developers.tossinvest.com/docs/auth)
- [Vercel 고정 IP 안내](https://vercel.com/kb/guide/can-i-get-a-fixed-ip-address)

## 토큰 보관과 갱신

- OAuth 2.0 Client Credentials 방식, form-urlencoded 요청을 사용합니다.
- 토스는 한 클라이언트의 새 토큰이 이전 토큰을 무효화합니다. 다른 프로그램이 같은 클라이언트 키로 별도 발급하지 않도록 운영해야 합니다.
- `portfolio.market_data_tokens`에 AES-256-GCM으로 암호화해 저장합니다. 클라이언트 키·시크릿에서 공급자 전용 암호화 키와 캐시 식별자를 파생합니다.
- PostgreSQL advisory lock과 프로세스 내 진행 요청 공유로 여러 인스턴스의 발급을 직렬화합니다. 토큰 발급 순간에만 외부 요청을 잠금 안에서 실행합니다.
- 만료 전 여유 시간을 두고 갱신하며, 401을 받은 토큰만 거부된 것으로 전달해 갱신합니다. 다른 인스턴스가 이미 갱신했다면 새 토큰을 재사용합니다.
- 403은 재발급하지 않습니다. 429는 제한된 대기 후 한 번 재시도합니다.
- 토큰 저장소는 RLS가 켜진 비공개 테이블이며 `PUBLIC`·`anon`·`authenticated` 권한을 차단합니다. API 응답에 키·토큰·원본 인증 오류를 포함하지 않습니다.

마이그레이션: `supabase/migrations/20261021152532_market_data_tokens.sql`. 현재 연결된 DB에 적용하고 접근 권한을 확인했습니다.

## 현재가와 일간 손익

토스 `/prices`는 전일 종가를 직접 제공하지 않으므로 별도 일봉 API를 사용합니다.

1. 시세 응답에 찍힌 거래 시각을 한국 또는 뉴욕 현지 거래일로 변환합니다.
2. 그 거래일 자정 이전의 일봉 중 가장 최근 종가를 선택합니다.
3. 현재 거래일 봉과 다른 통화의 봉을 제외합니다.
4. 동일 종목·거래일의 전일 종가는 공유 캐시로 1시간 보관합니다.

주말에는 마지막 체결 거래일을 기준으로 계산합니다. 시세 시각이 없거나 종가 조회에 실패하면 일간 손익은 미확인으로 남기며 0으로 만들지 않습니다. 첫 조회에는 일봉 요청이 추가되므로, 200종목 일괄 현재가를 사용하더라도 콜드 조회 전체가 한 요청으로 끝나는 것은 아닙니다.

토스 종목 목록은 거래소별로 조회하고 6시간 캐시합니다. 지원하는 거래소에서 실제 제공되는 종목만 검색됩니다. 미국 티커의 앱 기존 입력 제한은 그대로 적용됩니다.

## 한도와 장애 처리

- 토스 우선: 가격 갱신 요청당 최대 200개 보유·후보 종목.
- KIS 우선: 기존 최대 30개.
- 토스 장애 때 KIS 보조 조회는 최대 30개까지만 시도합니다. 초과 종목의 이전 가격은 덮어쓰지 않습니다.
- 종목 시세는 유효한 양수 가격만 저장하고 공급자 이름을 함께 기록합니다.
- 다른 통화나 요청하지 않은 코드의 가격을 해당 자산에 적용하지 않습니다.
- 프로세스 내 API 그룹별 호출 간격과 429 재시도를 적용합니다. 공급자 전체 한도는 여러 인스턴스의 총 요청량에 영향을 받으므로 실제 운영 부하를 확인해야 합니다.

## 검증

```bash
cd apps/web
node --test tests/*.test.mjs
pnpm exec tsc --noEmit
pnpm build
# 실제 DB에 합성 토큰을 저장하되 전체 롤백, 실제 토스 호출 없음
PF_TOSS_TOKEN_DB_TEST=1 pnpm dlx tsx tests/toss-token-cache.integration.mts
```

모의 응답으로 토큰 발급·동시 요청·콜드 인스턴스 재사용·401 갱신·403 차단·429 재시도, 다건 가격과 일간 종가·거래소 매핑, 공급자 전환·부분 실패·호출 제한·로그인 및 소유자 경계를 검증합니다.

토스 실제 키와 허용 IP가 아직 설정되지 않아 **실서비스 토스 인증 및 시세 수신은 미검증**입니다. 현재 코드 배포만으로 토스 실조회가 활성화되었다고 판단하면 안 됩니다.
