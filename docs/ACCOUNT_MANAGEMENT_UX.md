## 검증

- 전체 자동 테스트 79개 통과. 통화 분리·미확인 가격·캡처 대체·검산 테스트 추가.
- 로컬 QA 계정에서 대상 선택만으로는 종목이 이동하지 않음을 확인.
- 확인 후 이동과 원래 계좌 복원, 다시 선택 후 취소를 실제 화면에서 검증. 수량 10주·단가 USD 180 유지.
- 모바일 390px 화면에서 이동 확인 패널과 실행 버튼 가독성 확인.
- QA 계정에는 반복 검증을 위한 빈 `QA 이동 확인용` 계좌를 추가했으며 일반 사용자 자산은 수정하지 않음.
