# 리밸런싱 허용 오차

설정 위치: **목표 설계 → 리밸런싱 허용 오차 → 계산 기준**.
리밸런싱 화면의 **기준 변경**에서도 이동할 수 있습니다.

## 전체 자산 비중 기준 (%p)

기존 방식입니다. 목표 20%에 ±2%p라면 18~22%를 허용합니다.
기존 사용자의 기준과 설정값은 자동으로 바뀌지 않습니다.

## 각 포트 목표 금액 기준 (%)

각 포트의 목표 금액에 상대 오차를 적용합니다.

- 목표 금액 = (현재 전체 평가액 + 추가 투입금) × 목표 비중
- 허용 금액 = 목표 금액 × (1 ± 허용 오차율)
- 예: 목표 금액 1,000만 원, ±10% → 900만~1,100만 원
- 예: 목표 비중 5%, ±10% → 전체 비중으로는 4.5~5.5%
- 예: 목표 비중 20%, ±10% → 전체 비중으로는 18~22%

목표 0%의 상대 오차 범위는 0원입니다. 보유 자산이 있으면 조정 대상으로 남습니다.
설정 범위는 비중 기준 0~30%p, 목표 금액 기준 0~100%입니다.
두 방식의 숫자는 각각 저장되므로 기준을 바꿔도 이전 숫자를 다시 입력할 필요가 없습니다.

## 계산과 확인

**허용 범위 밖인 포트는 자동으로 조정을 제안**합니다. 범위 안인 포트만 기본값이 **제안 없음**이며, 직접 종목을 선택하면 목표 비중까지 조정할 수 있습니다. 범위 판정은 추가 투입금을 포함한 총자산 기준입니다. 자동 매수는 첫 등록 후보, 매도는 평가액이 큰 보유 종목부터 검토하며, 주식 후보·보유 주식 없이 가상자산만 있는 포트는 등록된 가상자산을 소수점 단위로 계산합니다. 직접 선택한 종목과 거래 제외 설정을 우선하고, 신규 자금 모드에서는 매도하지 않습니다. 가격·예산·최소 수량 때문에 거래를 제안하지 못할 수 있으며, 최종 허용 범위는 모든 제안 반영 후 다시 판정합니다.

주식은 1주, 등록한 비트코인 등 가상자산은 소수점 8자리 단위로 계산합니다. 선택한 가상자산의 매수·매도도 공동 예산과 최종 예상 비중에 포함합니다. 실제 거래소의 최소 주문금액·수량 단위는 별도로 확인해야 합니다.

두 기준은 공동 매수 예산 배분의 우선순위와 최종 범위 판정에 적용됩니다.
목표 금액 기준에서는 각 포트마다 다른 금액 허용 폭을 사용합니다.
추가 자금이 있으면 기존 총액 대신 추가 후 총액으로 목표 금액을 다시 계산합니다.

리밸런싱 화면 상단에서 현재 기준을 확인하고, **포트별 계산 상세**를 펼치면
목표 금액과 허용 금액의 하한·상한을 볼 수 있습니다.
목표 금액 기준의 범위 밖 결과에는 부족·초과 금액을 표시합니다.
1주 단위, 후보 가격, 제외 설정, 매도 불가능한 직접 입력 자산 등으로
모든 포트가 허용 범위에 들어오지 못할 수 있습니다.

제안은 검토용이며 실제 주문이나 보유 수량을 자동 변경하지 않습니다.
