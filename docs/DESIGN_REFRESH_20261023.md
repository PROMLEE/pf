# 금융 앱 디자인·사용성 개선

2026-10-23. 포트리듬의 자산 점검 흐름에 맞춰 토스증권·로빈후드 공식 화면과 안내를 참고했습니다.

## 참고한 요소

- [토스증권](https://www.tossinvest.com/): 종목 아이콘과 이름을 왼쪽에, 비교할 금액을 오른쪽에 정렬하는 목록, 명확한 탭과 정보의 우선순위.
- [Robinhood Investing](https://robinhood.com/us/en/invest/): 큰 평가액, 간결한 손익 표시, 주요 행동이 바로 보이는 구성.
- [Robinhood Investing tools](https://robinhood.com/us/en/support/articles/investing-tools/): 일간·전체 손익, 평가액 등 사용자가 선택하는 보유 목록 표시 기준.

브랜드 색상과 기능은 포트리듬의 목표 비중·리밸런싱 목적에 맞춰 구성했습니다.

## 변경 사항

### 대시보드

- PC·모바일의 중복 요약·목록을 하나의 반응형 구성으로 합쳤습니다.
- 총 평가액 → 선택한 기간의 손익 → 보유 자산 순으로 배치합니다.
- 손익 전환과 정렬은 같은 줄에 유지하고, 개별 자산도 같은 기간으로 표시합니다.
- 포트 비중·자산 추이·자산 관리로 이동하는 동선을 제공합니다.
- PC에서는 비중 그래프와 목표 비중 점검을 오른쪽에 함께 표시합니다. 좁은 화면에서는 요약과 종목 목록을 우선합니다.
- 모바일에서도 환율 손익 포함 설정이 현금·종목 목록에 동일하게 전달됩니다.

### 공통 화면

- 밝은 기본 배경과 중립적인 사이드바, 얇은 구분선으로 구성합니다. 다크 모드는 기존 버튼과 기기별 선택을 유지합니다.
- 메뉴·하위 화면은 선택 상태가 분명한 탐색 메뉴와 밑줄 탭으로 정리합니다.
- 큰 금액, 보조 단위, 설명의 글자 크기와 대비를 구분합니다. 숫자는 같은 폭으로 표시합니다.
- 계좌 목록·리밸런싱 계획·입력 폼·상세 정보에 같은 간격과 버튼 형태를 적용합니다.
- 정적인 조회 화면의 ‘저장됨’ 표시를 제거하고, 수정이 가능한 화면에서 저장 상태를 표시합니다.
- 모바일 갱신 버튼은 아이콘으로 간소화하되 접근성 이름을 유지합니다.

### 비중 그래프

- 중복 제목을 제거하고, 기본 중앙 값은 총평가액의 만원·억원 단위 요약 또는 목표 합계로 표시합니다.
- 선택한 포트의 평가액·현재/목표 비중·차이는 상세에서 확인합니다.
- 선택 해제 버튼과 Escape 키를 지원합니다.
- 포트 이름 위로 마우스가 지나갔다고 선택이 바뀌지 않게 했습니다. 그래프 조각의 hover·포커스 및 이름 클릭은 지원합니다.
- 목표 비중 수정과 리밸런싱 화면으로 바로 이동할 수 있습니다.

## 검증 범위

- 로컬 QA 계정으로 PC 대시보드·비중 화면, 실제 innerWidth 390px의 모바일 대시보드·비중 화면을 확인했습니다.
- 일간/전체 손익 전환, 이름순 정렬과 원래 정렬 복원, 포트 선택·상세 표시·해제, 라이트/다크 전환을 확인했습니다. 검증 후 라이트·전체 손익·평가액 높은순으로 복원했습니다.
- 확인한 모바일 화면의 scrollWidth가 innerWidth를 넘지 않았습니다.
- 이어지는 작업 중 브라우저 연결이 사용할 수 없게 되어, 최종 계좌 관리·리밸런싱 화면의 추가 조작 검증은 수행하지 못했습니다. 해당 화면은 스타일 변경 및 기존 자동 회귀 검사 범위입니다.
- 실제 사용자의 보유 수량·평단·예수금·계좌 정보는 수정하지 않았습니다. QA 계정의 기존 자동 시세 조회는 앱 동작에 따라 수행됐습니다.
- 자동 테스트 282개, TypeScript 검사, 프로덕션 빌드가 통과했습니다. 운영 배포 후 실제 기기의 키보드·장문 종목명 등 모든 조합을 검증했다는 의미는 아닙니다.
