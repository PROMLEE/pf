# 자주 묻는 질문

## 내 자산은 어디서 수정하나요?

대시보드에서 자산을 누르고 **이 자산 수정**을 선택하면 해당 입력 항목으로 이동합니다. 메뉴의 **자산 수정**에서도 주식·가상자산·현금·기타를 관리할 수 있습니다. 주식은 해당 종목의 **저장**, 가상자산·직접 입력 자산은 **변경 내용 저장**을 눌러 반영합니다.

## 비트코인 매입단가는 어디에 입력하나요?

**자산 수정 → 가상자산 → 코인당 매입가 (원)**입니다. 코인 1개당 평균 매입단가를 입력합니다. 총 매입금액만 알고 있다면 총 매입금액을 보유 수량으로 나눈 값을 확인해 입력하세요.

## 추가 자산 이름은 어디서 바꾸나요?

**자산 수정 → 기타 직접 입력 자산 → 자산 이름**에서 변경하고 저장합니다. 대시보드의 현금·기타 항목을 누른 뒤 수정으로 들어가도 같은 위치로 이동합니다. 주식·가상자산 이름은 검색한 종목 정보로 표시하며 직접 입력 자산처럼 임의 이름을 편집하는 필드는 없습니다.

## 내 현금이나 RP도 넣을 수 있나요?

직접 입력 자산으로 이름·금액·통화·포트를 등록합니다. KRW는 원화 평가액, USD는 달러 금액입니다. 이 항목은 총 평가액과 포트 비중에는 포함되지만 매입단가 기반 손익에는 포함되지 않습니다.

## 수량도 증권사나 빗썸에서 자동으로 읽어오나요?

현재 수량과 매입단가는 캡처 검토 또는 직접 입력으로 관리합니다. KIS와 빗썸 연동은 가격·종목 확인에 사용하며 미래에셋·메리츠·빗썸의 실제 계좌 잔고를 자동 동기화하지 않습니다. 실제 매매 후에는 앱의 수량도 수정해야 합니다.

## 가상자산 가격을 보려면 토큰이 필요한가요?

현재 사용하는 빗썸 KRW 공개 현재가 조회는 계좌 API 토큰이 필요하지 않습니다. 계좌 잔고 조회나 거래를 하는 Private API와는 별개입니다.

## 환율은 자동인가요?

자동 모드에서는 Frankfurter를 통해 ECB 일일 USD/KRW 기준환율을 확인합니다. **목표 설계 → 환율·기타 설정**에서 모드와 적용 값을 확인하고 직접 입력으로 바꿀 수도 있습니다. 실제 증권사 환전 가격이나 초단위 환율은 아닙니다.

## 현재가가 증권사 앱과 다른데요?

조회 간격, 거래 시장·시간대, 지연된 응답, 환율 또는 캡처 가격 대체 여부가 다를 수 있습니다. 가격 출처·조회 시각을 확인하고 새로고침합니다. 미국 종목은 티커와 거래소도 확인합니다.

## 일간 손익이 조회 중이거나 정보 없음으로 표시돼요.

일간 손익에는 현재가와 전일 종가가 모두 필요합니다. **가격 갱신** 후에도 정보가 없으면 종목코드·거래소, KIS 키 설정, 외부 API 응답 상태를 확인합니다. 매입단가는 전체 손익에 필요한 값이며 전일 종가를 대신하지 않습니다. 일부 종목만 확인됐다면 집계 수를 보고 전체 자산의 일간 수익으로 오해하지 않도록 합니다.

## 전체 손익이 계좌의 총손익과 다를 수 있나요?

앱은 현재 보유 종목의 매입단가와 평가 가격을 비교합니다. 실현손익·배당·수수료·세금·매수 당시 환율은 따로 집계하지 않습니다. 매입단가를 모르는 종목도 손익 집계에서 제외됩니다.

## 허용 오차 ±5%p는 어디서 바꾸나요?

**목표 설계 → 리밸런싱 허용 오차**에서 설정합니다. 리밸런싱의 **기준 변경**도 이 화면으로 이동합니다. 목표 20%에서 ±5%p이면 허용 범위는 15~25%입니다.

## 자산 배정과 매수 후보는 어떻게 다른가요?

자산 배정은 **이미 보유한 자산**의 포트를 정합니다. 리밸런싱 하단의 매수 후보는 **앞으로 매수에 사용할 주식**을 포트별로 정하고, 같은 종목코드의 자동 배정 규칙으로도 사용합니다. 후보만 등록해도 실제 보유 수량이나 평가액이 생기지는 않습니다.

## 자동 배정이 내가 정한 포트와 다르게 보입니다.

주식의 직접 배정이 자동 규칙보다 우선합니다. **자산 배정**에서 직접 지정 여부를 확인합니다. 자동으로 되돌리려면 해당 항목을 **자동**으로 선택하고 저장합니다. 잘린 이름보다 시장·종목코드를 확인하는 것이 정확합니다.

## 리밸런싱 제안이 목표 비중과 정확히 같지 않아요.

주식은 1주 단위로 계산하고 사용 가능한 예산도 제한됩니다. 제외 종목과 후보 가격에 따라 남는 차이가 생깁니다. 가상자산 거래는 주식 제안의 결과 미리보기에 포함되지 않습니다.

## 리밸런싱 버튼이 실제 매매를 하나요?

실제 주문을 실행하지 않습니다. 제안 수량을 검토한 뒤 사용 중인 증권사·거래소에서 직접 거래하고 보유 정보를 수정합니다.

## 그래프는 눌러볼 수 있나요?

원형 그래프의 조각이나 범례를 선택하면 해당 포트의 평가액·현재 비중·목표·차이가 표시됩니다. 데스크톱은 마우스 이동도 지원하고 모바일은 탭으로 선택합니다. **현재 / 목표**를 바꾸면 해당 비중 기준으로 정렬됩니다.

## 기록 화면의 증감이 오늘 수익인가요?

기록 기간 평가액 변화나 순입금 제외 증감은 일간 종목 손익과 다른 지표입니다. 새 자산 등록이나 수량 수정도 기록의 평가액 변화를 만듭니다. 일간 종목 손익은 대시보드의 **일간 수익**에서 확인합니다.

## 캡처에 이름과 계좌번호가 보여도 서버에 저장되나요?

앱의 잔고 이미지는 브라우저에서 OCR 처리하며 서버에 업로드하지 않습니다. 저장 버튼을 누르면 검토한 종목 정보와 사용자가 입력한 증권사·계좌 구분이 저장됩니다. 공유할 캡처에는 개인 정보가 보이지 않도록 준비하세요.

## 카카오와 네이버에 각각 로그인하면 같은 데이터인가요?

현재는 제공자별 계정을 자동 합치지 않습니다. 평소 사용한 동일한 로그인 제공자를 선택하세요. 기존 서비스와 같은 사용자 테이블을 사용하더라도 다른 도메인의 세션이 자동으로 공유되는 것은 아닙니다.

## 네이버 서비스 설정 오류가 나요.

운영자는 배포의 `NEXTAUTH_URL`, `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`과 네이버 앱에 등록한 Callback URL을 함께 확인합니다. 운영 도메인의 콜백은 `https://pf.promleeblog.com/api/auth/callback/naver`입니다. 콜백이 등록돼 있어도 실행 중인 환경 변수·제공자 앱·로그인 요청 주소가 서로 다르면 문제가 생길 수 있습니다. 설정 변경 후 재배포 여부도 확인합니다.

## 접속할 때마다 KIS 토큰 발급 안내가 와요.

현재 앱은 만료 전 토큰을 재사용하도록 구성돼 있습니다. 접속마다 계속 안내가 오면 운영자가 `portfolio.kis_token_cache` 테이블, DB 연결, 앱 키 변경 여부와 발급 오류 로그를 확인해야 합니다. 키·시크릿이나 발급된 토큰을 화면·문서·로그에 공개해서 확인하지 않습니다.
