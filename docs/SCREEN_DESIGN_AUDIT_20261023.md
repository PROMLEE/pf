# 전체 화면 디자인 점검 범위

2026-10-23. 앞선 디자인 변경은 대시보드·비중 화면과 공통 스타일 중심이었다. 이번에는 앱의 17개 view, 별도 공개·관리자 경로와 편집 창을 목록으로 대조했다. **소스 점검은 해당 화면의 실제 브라우저 조작 검증을 의미하지 않는다.**

## 유지한 동작

- 메리츠 동기화 자산은 읽기 전용, 접속 시 한 번 동기화와 수동 동기화 유지.
- 현금 반영 체크박스의 좁은 클릭 영역 유지.
- 모바일 기록 그래프의 복잡한 원 단위 눈금은 다시 추가하지 않음. 점 선택 상세와 일별 기록 유지.
- 계산·거래·소유권·동기화 API는 이번에 변경하지 않음. 사용자 자산 데이터를 수정하지 않음.

## 검증 한계

내장 브라우저 연결을 사용할 수 없어 이번에는 네이티브 Whale에서 공개 로그인·가이드를 확인했다. 앞선 QA 계정의 PC·390px 대시보드·비중 검증 결과와 이번 소스 점검을 구분했다. 모든 화면의 PC·모바일·다크 모드 조합을 실제로 검증했다는 의미는 아니다. 특히 로그인 후 변경된 캡처 입력·알림 설정·관리자 화면은 실제 기기 시각 검증이 남아 있다.
