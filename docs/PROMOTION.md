## 서비스 소개글

### 내 자산은 얼마나 늘었을까. 내 계획대로 투자하고 있을까.

국내 주식은 증권사에서, 미국 ETF는 다른 계좌에서, 비트코인은 거래소에서 확인하다 보면 전체 자산의 방향을 한눈에 보기 어렵습니다. 종목별 수익을 알고 있어도 내가 정한 비중과 얼마나 달라졌는지 다시 계산해야 합니다.

PortRhythm은 그 점검을 위한 개인 포트폴리오 관리 서비스입니다.

먼저 투자 기준을 만듭니다. 미국 지수, 한국 지수, 우량주, 금, 비트코인, 현금처럼 나에게 필요한 포트를 만들고 목표 비중을 정합니다. 분류 이름과 비중은 자유롭게 바꿀 수 있습니다. 내 계획에 맞게 자산을 배정하면 현재 구성과 목표의 차이를 원형 그래프로 확인할 수 있습니다.

![PortRhythm의 목표와 현재 비중 비교](screenshots/desktop-composition.jpg)

대시보드에서는 전체 평가액과 보유 종목을 확인합니다. 전체 수익과 일간 수익을 전환하면 종목별 손익도 함께 바뀝니다. 주식·가상자산을 선택하면 수량, 현재가, 평균 매입단가와 손익을 확인하고 수정 화면으로 이어집니다. 현금과 기타 자산은 이름과 금액을 직접 관리할 수 있습니다.

한국투자증권 API로 국내·미국 주식 가격을, 빗썸 공개 API로 원화 가상자산 가격을 주기적으로 확인합니다. 종목코드 검색과 증권사 잔고 캡처 검토로 보유 정보를 등록하고, 미국 자산은 자동 기준환율이나 직접 설정한 환율로 원화 합산합니다.

![자산과 손익을 보여주는 대시보드](screenshots/desktop-dashboard.jpg)

비중이 계획에서 벗어났다면 리밸런싱을 검토합니다. 허용 오차를 정하고 매도 후 매수 또는 신규 자금 매수 방식을 선택하면 주식의 예상 매수·매도 수량과 조정 후 비중, 남는 자금을 볼 수 있습니다. 당장 움직이고 싶지 않은 종목은 이번 조정에서 제외할 수도 있습니다.

![리밸런싱 조정 제안](screenshots/desktop-rebalance.jpg)

포트별 자산 추이와 입출금도 기록합니다. 모바일에서는 핵심 숫자와 종목 현황을 빠르게 확인하고, 비중과 리밸런싱 화면으로 이동할 수 있습니다.

PortRhythm은 주문을 실행하거나 투자 수익을 약속하지 않습니다. 계좌 수량은 사용자가 등록·수정하며, 손익과 제안은 확인 가능한 가격·매입단가를 기준으로 계산합니다. 거래와 비용은 실제 증권사·거래소에서 확인합니다.

## 짧은 소개글

PortRhythm은 국내·미국 주식, 가상자산, 현금을 나만의 목표 비중으로 관리하는 개인 포트폴리오 서비스입니다. 현재 비중을 원형 그래프로 비교하고, 전체·일간 손익과 종목 상세를 확인하며, 허용 오차에 맞는 주식 리밸런싱 수량을 검토할 수 있습니다. 실제 거래는 직접 진행하고 수량은 앱에서 관리합니다.

## 제품 소개용 3분 시연 순서

| 순서 | 보여줄 화면 | 설명 |
| --- | --- | --- |
| 1 | 대시보드 | 전체 평가액, 전체·일간 전환, 종목 목록 |
| 2 | 자산 상세 | 수량·매입단가·손익·수정 연결 |
| 3 | 목표 설계 | 사용자 정의 포트, 목표 비중, 허용 오차 |

테스트 데이터로 시연하고, 실제 주문 없이 검토까지만 제공한다는 점을 설명합니다.

## 공개 표현 기준

| 사용할 표현 | 함께 설명할 조건 |
| --- | --- |
| 주기적인 시세 조회 | 주식 약 5분, 가상자산 약 1분, 외부 API 상태에 따라 지연 |
| 전체·일간 손익 | 확인 가능한 종목 기준, 실현손익·환차손익·비용 집계 제외 |
| 리밸런싱 제안 | 주식 정수 주 단위 참고 수량, 실제 주문 미실행 |
| 자동 환율 | ECB 일일 기준환율, 증권사 실시간 환전 호가와 다름 |

| 계정 저장 | 로그인 사용자별 데이터 저장, 소셜 제공자 간 자동 병합 없음 |
